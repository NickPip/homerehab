# Google Business Profile assets

Ready-to-upload images for the HomeRehab Google Business Profile.

| File | Use | Size |
|---|---|---|
| `logo-square-720.png` | Profile logo | 720 x 720 (1:1) |
| `cover-1024x576.jpg` | Cover photo | 1024 x 576 (16:9) |
| `photo-cover-1200x900.jpg` | Additional photo | 1200 x 900 (4:3) |
| `photo-team-1-1200x900.jpg` | Team photo | 1200 x 900 (4:3) |
| `photo-team-2-1200x900.jpg` | Team photo | 1200 x 900 (4:3) |

Derived from `public/small-logo.png`, `public/cover.jpg`, `public/doctor.jpeg`
and `public/doctor2.jpeg`.

Note: HomeRehab is a service-area business (therapists visit patients at home),
so there is no storefront exterior to photograph. Skip the "Add a storefront
photo" step in the Business Profile setup flow.
